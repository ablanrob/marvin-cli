# Marvin Documentation

Marvin (`mrvn-cli`) is an AI-powered software product development assistant that brings Product Owner, Delivery Manager, and Technical Lead personas to your project. It works as both a CLI tool and an MCP server for Claude.

- **[Personas](guides/personas.md)** — Understanding the three personas and what each one does
- **[CLI Reference](reference/cli.md)** — Complete command reference with all options and flags

- **[Document Types](reference/document-types.md)** — All artifact types, their fields, and lifecycle statuses
- **[Skills](guides/skills.md)** — Using and creating skills to extend persona capabilities
- **[Jira Integration](guides/jira.md)** — Bidirectional sync between Marvin artifacts and Jira issues
- **[Web Dashboard](guides/web-dashboard.md)** — Browsing your project data in a local web UI
